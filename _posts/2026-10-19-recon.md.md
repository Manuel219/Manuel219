Every penetration test starts with finding things out. Before touching a target, they collect usernames, email patterns, domains and the services the company runs. That groundwork decides where the rest of the test goes.

## Passive and active recon

**Passive recon** gathers open source data from the internet without touching the target's systems. I run DNS queries to find the IP addresses tied to the company, look for public email addresses, and identify the services it exposes.

**Active recon** interacts directly with the target, for example by scanning ports or fingerprinting a firewall. It gives more detail but can show up in the target's logs, so get written scope first.

Recon typically finds:

- Usernames and email patterns
- IP addresses and subdomains
- Running services and open ports
- Certificates and the protocols in use
- The web application firewall (WAF) in front of a site

## Tools I use

### Domains and DNS

| Tool | What it does |
|------|--------------|
| [Whois](https://who.is) | Domain registration and ownership details |
| [DNSdumpster](https://dnsdumpster.com) | DNS records and host mapping for a domain |
| DNS lookup | Find the IP addresses and records for a domain (dig, nslookup) |
| [crt.sh](https://crt.sh) | Certificate transparency logs: misissued certificates and forgotten subdomains |
| [Subfinder](https://github.com/projectdiscovery/subfinder) | Fast subdomain discovery |
| [Amass](https://github.com/owasp-amass/amass) | Attack surface mapping and enumeration, maintained by OWASP |
| [Nmap](https://nmap.org) | Find open ports and the services behind them |
| [SSL scan](https://www.ssllabs.com/ssltest/) | Spot insecure transfer protocols and weak ciphers |

### Emails and people

| Tool | What it does |
|------|--------------|
| [Hunter.io](https://hunter.io) | Email addresses and the format a domain or organisation uses |
| [theHarvester](https://github.com/laramies/theHarvester) | Collect IPs, emails and hostnames from open sources |
| [Have I Been Pwned](https://haveibeenpwned.com) | Check whether an email or account appeared in a data breach |
| [Maltego](https://www.maltego.com) | Visual link analysis for investigations |

### Internet-wide search

| Tool | What it does |
|------|--------------|
| [Shodan](https://www.shodan.io) | Search engine for open services across the internet |
| [Censys](https://censys.io) | Internet-wide scan data on hosts and certificates |
| [ZoomEye](https://www.zoomeye.ai) | Internet asset discovery search engine |

### Web and WAF

| Tool | What it does |
|------|--------------|
| robots.txt | Paths a site asks crawlers to skip, which are often worth a look |
| [wafw00f](https://github.com/EnableSecurity/wafw00f) | Identify the WAF in front of a site |
| [WhatWaf](https://github.com/Ekultek/WhatWaf) | WAF detection with bypass suggestions |
| [jwt.io](https://jwt.io) | Decode, verify and debug JSON Web Tokens |
| [inSSIDer](https://www.metageek.com/products/inssider/) | Wi-Fi network scanner for Windows |
| [Bright Data](https://brightdata.com) | Proxy network and web scraping platform |

### Frameworks

| Tool | What it does |
|------|--------------|
| [SpiderFoot](https://www.spiderfoot.net) | Automated OSINT collection across many sources |
| [Recon-ng](https://github.com/lanmaster53/recon-ng) | Modular recon framework with a Metasploit-like workflow |
| [OSINT Framework](https://osintframework.com) | A directory of free OSINT tools and resources |
